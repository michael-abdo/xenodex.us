The Method

Behavior can be classified using AI

THE CORE PREMISE

If you have enough data and compute, you can accurately classify personality types

Behavior can be classified using AI. The implication is profound: with sufficient data and computational power, we can accurately identify an individual's personality type from their digital footprint.

But the breakthrough isn't just in the classification - it's in understanding that AI already knows these patterns. Text-based LLMs can embody people's language patterns; they just don't know the abstracted language pattern yet.

The type is already encoded in these models because they can recognize behavioral signatures.

DATA ARCHITECTURE

Curated, Hybrid, and Synthetic Approaches

Our data pipeline combines three approaches: curated datasets based on Jungian cognitive function analysis, hybrid annotation with AI pre-labeling, and synthetic generation for scale.

A1) Curated Dataset

  • • Custom dataset based on recent data analysis of Jungian cognitive functions
  • • Currently 2k+ samples with unlimited growth potential
  • • Inter-rater reliability threshold: ICC ≥ 0.85

A2) Hybrid Annotation

  • • Fine-tuned BERT/RoBERTa/DeBERTa classifiers
  • • 75-85% accuracy vs human typist labels
  • • 75-85% cost reduction over pure human annotation

A3) Synthetic Generation

  • • AI celebrities generating training data
  • • Ensures synthetic personalities don't just mimic training data
  • • Psychologically plausible personality generation

Dynamic scoring system where AI and human validators compete on accuracy metrics.

INFERENCE METHODS

From Binary Classification to Probabilistic Inference

Our inference approach balances computational efficiency with uncertainty quantification, supporting both binary classification for speed and probabilistic inference for nuanced applications.

D1) Binary Classification

  • • Specific personality traits classified as binary
  • • Calibrated confidence thresholds
  • • Optimized false positive/negative trade-offs
  • • Edge case handling near decision boundaries

D2) Probabilistic Inference

  • • Calibrated probability distributions
  • • Uncertainty metrics for downstream applications
  • • Ground truth validation of probabilistic outputs
  • • Computational overhead optimization

Validation Approach:

Phase 1 (Current):

Achieve consistent AI typing that matches expert human typists - validates system reliability and pattern recognition accuracy.

Phase 2 (Planned):

External biological validation through genetic analysis to determine if AI-identified patterns correlate with measurable DNA differences.

Phase 2 will provide the first empirical evidence that behavioral patterns reflect genuine biological categories.

THE BREAKTHROUGH INSIGHT

AI Already Knows These Patterns

The remarkable discovery is that large language models already encode personality types through their training on human text. They can embody people's language patterns - they just don't know the abstracted framework yet.

To fully abstract and solidify this pattern consistently, we need to train our own model. But to generate enough data for that model, we can use synthetic OR real-world data - it doesn't matter.
